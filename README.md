# Docket

Уеб kanban за лични задачи. Пишеш както мислиш или поставяш цял имейл — AI предлага задачи и колони, ти потвърждаваш. Колоните изчезват в архив, щом всичко в тях е свършено.

Виж [SETUP.md](SETUP.md) за настройка на собствен Google Apps Script бекенд и Groq ключ, и [devpost/](devpost/) за пълната документация на проекта (scope, PRD, спецификация, build checklist).

## Локално стартиране

```bash
python3 -m http.server 8000
```

После отвори `http://localhost:8000`.
